# Проверка релиза «Захар и Тедди»

Дата: 12 сентября 2026 года.

## Выполнено

- 55 автоматических тестов прошли: 47 проверок математического ядра, генерации, валидации, состояния и хранения; 8 интеграционных проверок DOM с подключением настоящего приложения.
- Для каждого из 30 уровней проверено 5000 задач — всего 150 000. Проверяются целочисленность, диапазоны, деление, остаток, промежуточные результаты, соответствие отображаемого выражения AST и единственность правильного варианта в логических задачах.
- Проверены фиксированный seed, отличие повторного набора, отсутствие дублей и обязательное смешивание навыков в испытаниях.
- В DOM проверены последовательности 1 → 5 = 15 и 1 → 5 → 3 = 153, физический и экранный пути ввода, смешанный ввод, устаревшая позиция курсора, удаление, очистка, запрет букв и знаков. Нативный физический ввод моделируется через beforeinput/input; это не проверка настоящего устройства.
- Проверены однократная обработка Enter, пустое поле и автоматическое восстановление фокуса после смены задачи.
- Проверены два поля остатка и переключение Enter, адресация экранной клавиатуры последнему сфокусированному полю.
- Проверены ошибки, три сердца, неуспешная попытка, звёзды, разблокировка, лучший результат, повторное открытие сохранений и полный сброс с отменой.
- Проверены свободная тренировка и сохранение задания при открытии справочника, приостановка перехода в настройках.
- Production build успешно создаёт dist; проверяются синтаксис модулей и локальные ссылки на ресурсы.
- Использован именно предоставленный пользователем спрайт-лист: Захар в белом худи, чёрно-белый Тедди. Изображение не перерисовывалось; CSS выбирает области с позами. Исходный JPEG сохранён без изменения байтов.
- Подготовлен workflow GitHub Pages: публикация зависит от прохождения Node/DOM и браузерных проверок.

## Что пока не подтверждено

- Настоящая браузерная проверка: сервер проверки запустился, но доступ браузера к нему был заблокирован политикой среды. Обход ограничения не выполнялся.
- Поэтому визуальная компоновка, реальные NumPad/Tab, сенсорный ввод, Safari/iPad, 200% масштаб и финальная нарезка поз не считаются проверенными в настоящем браузере.
- Подготовлены Playwright-сценарии для Chromium и WebKit, включая ширины 320, 390, 768, 1024 и 1440 px, длинные выражения и увеличение текста. Проверена обнаруживаемость тестов; выполнение браузеров в этой среде не заявляется. Полноценный браузерный прогон должен пройти в GitHub Actions до деплоя.
- WebMCP проверен с тестовым реестром в DOM; настоящий поддерживаемый браузер для этой проверки недоступен.
- Подключение GitHub подтверждено приложением, но инструменты работы с GitHub не появились среди доступных этой сессии операций. Репозиторий не создан, push и релиз Pages не выполнены. Публичной ссылки на игру пока нет.

## Отличия от переданного ТЗ

- Авторизация полностью исключена по прямому пожеланию пользователя. Кодового экрана, session auth и тестов кодового слова нет.
- Это отдельный второй проект. Первый не изменён. Сохранён исходный стек vanilla JavaScript и подход с отдельным математическим ядром. UI и конфигурация расширены для карты из 30 уровней.
- Для специальных случаев уровня 14 сохранены запрошенные делители 10 и 100. В остальных задачах делитель однозначный.
- Причина прежнего 15 → 51, устройство нового ввода, генерации, сохранения и список файлов подробно описаны в README.md.
