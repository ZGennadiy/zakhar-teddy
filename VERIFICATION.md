# Проверка релиза «Захар и Тедди»

Дата: 13 сентября 2026 года. Исправление показа маскотов подготовлено относительно main `592a06ed2c7cfbb579ef965fd6124b1528f2e8f8`.

## Что изменено

- Удалены CSS-окна в общем спрайт-листе, проценты background-position/background-size и multiply-смешивание фона.
- Из нового листа пользователя вырезаны четыре самостоятельных RGBA PNG: neutral, correct, wrong, complete. Персонажи не генерировались заново и не перерисовывались.
- Холст каждой картинки — 512 × 384, общая линия стоп, прозрачный запас по краям. Белая одежда и шерсть остаются непрозрачными; сглаженные края сохраняют частичный alpha.
- На главной, в задаче и в результатах используется обычный img с object-fit: contain. Реакция переключает файл и доступное текстовое описание. Все позы предзагружаются.
- На узком экране иллюстрации отведено отдельное место над кнопкой начала.
- В artwork сохранён новый исходный лист; scripts/prepare-mascots.py воспроизводит вырезание. Зависимости обработки картинок не нужны ни игре, ни npm-сборке.

## Проверено для этого обновления

- `npm test`: **63 passed, 0 failed**. Это 47 проверок ядра, 9 DOM-проверок, 6 проверок маскотов и 1 HTTP-проверка.
- По 5000 задач на каждый из 30 уровней — 150 000. Проверены диапазоны, целочисленность, точное деление, остаток, промежуточные результаты AST, варианты ответов, seed и отсутствие дублей.
- Сохранились проверки ввода 15/153, клавиатуры и экранных кнопок, однократного Enter, фокуса, остатка, жизней, звёзд, повторов, сохранения и сброса.
- PNG декодируются в тестах: проверяются настоящий alpha-канал, прозрачные поля, видимые непрозрачные персонажи, белые детали, сглаживание и контрольные суммы.
- Реальные обработчики игры в DOM переключают нейтральную позу → размышление → повтор → успех → объятие после завершения уровня.
- Сервер отдаёт все четыре PNG с image/png по корневому пути и /zakhar-teddy/.
- `npm run build`: успешно. Все новые картинки и модуль маскотов включены в dist; исходный лист из artwork туда не попадает.
- `npm run test:e2e -- --list`: обнаружены 40 сценариев для Chromium и WebKit. Это проверка загрузки тестов, **не их браузерное выполнение**.
- Новые позы визуально просмотрены на белом, сиреневом и тёмном фоне. Соседних персонажей в подготовленных картинках нет.
- `git diff --check`: ошибок нет.

## Что ещё должен подтвердить CI

Локальный браузер ранее не получил доступ к адресу проверки из-за политики среды; ограничение не обходилось. Поэтому новое расположение картинок и добавленные браузерные сценарии должны пройти в GitHub Actions после загрузки файлов.

Добавлен tests/browser/mascots.spec.js: ширины 320/390/768/1440 px, настоящая загрузка каждого PNG, отсутствие CSS-спрайта, целостное размещение картинки, переключение всех поз при прохождении уровня и снимки для отчёта CI. Существующие браузерные проверки ввода, прогресса и 200% текста сохранены. Сценарий физического NumPad по-прежнему предназначен для Chromium; в WebKit он пропускается.

Предыдущая базовая версия прошла [проверки запуска № 3](https://github.com/ZGennadiy/zakhar-teddy/actions/runs/34740008717): 56 Node/DOM/HTTP, 31 браузерный тест и один пропуск. Этот результат не переносится автоматически на текущее обновление картинок.

## Передача и ограничения

Подключение GitHub позволяет читать репозиторий, но ранее отклонило запись с 403 Resource not accessible by integration. Это обновление не отправлено и не опубликовано автоматически; подготовлен архив изменённых и новых файлов.

Исходный стек, математическая логика, ввод, сохранения, отсутствие авторизации и ссылка на Telegram не менялись. Реальные iPad, аппаратная клавиатура и поддерживаемое окружение WebMCP отдельно не проверены.
